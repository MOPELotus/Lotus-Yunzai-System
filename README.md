# Lotus-Yunzai 系统模块

这是 Lotus-Yunzai 的内置系统模块，由主仓通过 Git 子模块固定版本。

| 指令 | 用途 |
| --- | --- |
| `#状态` | 查看宿主运行状态和 Bun 版本 |
| `#帮助` | 查看系统指令 |
| `#诊断` | 查看运行时、运行时间和进程内存 |

在 [Lotus-Yunzai](https://github.com/MOPELotus/Lotus-Yunzai) 根目录运行 `bun scripts/bootstrap.ts` 初始化，再运行 `bun app.ts`。可从终端或已接入的 OneBot 私聊、群聊发送指令。
